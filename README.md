# Quantify Ledger - Inventory Management System

This repository contains the complete implementation of **Quantify Ledger**, a secure, concurrent, and highly scalable inventory management platform.

For exhaustive specifications regarding the database design, security measures, concurrent transaction locks, paginated APIs, and system components, see the official [DOCUMENTATION.md](file:///d:/inventory-management-system/DOCUMENTATION.md).

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm.cmd install`
2. Run the application in development mode:
   `npm.cmd run dev`
3. Access the application at `http://localhost:3000`.

### Credentials
- **Administrator**: `admin` / `admin123`
- **Warehouse Staff**: `warehouse` / `warehouse123`
